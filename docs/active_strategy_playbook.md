# 主动仓作战手册（Active Strategy Playbook）

**v2.0 — 2026-09-15（红队审计后降级版）**

> ## ⚠️ 红队审计结论（2026-09-15，commit 196154e）：**本策略已降级**
>
> 独立红队审计发现（团队负责人已独立复核确认）：
> - **统计不显著**：13 次做多事件，均值 +5.30%、t=2.146、**p=0.053**（双侧）——在 5% 水平下**无法拒绝「真实收益为零」**。Bootstrap 95% CI 含零；胜率 69% 的 Wilson 区间 [42%, 87%] 包含抛硬币。
> - **2 笔就是全部**：2021-01-04（+25.5%）与 2023-03-13（+18.1%）= **63.3% 的毛利**。去掉这两笔：11 笔均值 +2.30%、p=0.18，无结论。
> - **搜索偏差**：全平台审计出 28 个假设方向 + 24 个信号内自由度 → 5% 下期望假阳性 ≈1.4 个，**Bonferroni p = 1.0**。且假设与确认出自同一次探索会话（属机遇式扫描，非预注册），原始 p 值不能当确证性证据读。
> - **所有对照都跑不赢无脑规则**：无条件「每个周末都买」= +0.915%/笔（n=297）复利 **+363%**，远胜本信号的 +80.6%；同事件日「持有到月末」= +8.80% vs 我们 +5.30%；**安慰剂检验（随机非周末日、BTC 两日涨≥5%）均值 +7.73%、胜率 73.7%，比信号本身还好（p=0.75）**。
> - **可交易的那部分已衰减到零**：拆解「周五收盘→周一开盘」（开盘缺口，**我们拿不到**）与「周一开盘→T+2 收盘」（**我们实际拿的**）：2021-23 是 gap 5.07% / post-open 5.85%；**2024-26 是 gap 8.18% / post-open 4.49%；2025 单看 gap +10.84%、post-open −0.09%**——行情全部在开盘一次性定价，策略一分没拿到。
> - 触发频率同步枯竭：5/yr(2021) → 2 → 2 → 3 → 1(2025) → **0（2026 至今）**；最近一次做多事件是 2025-03-03（−0.21%）。
> - **另需注意**：手册 v1.0 引用的「缺口与 BTC 周末涨幅相关 0.823」**不可复现**——用原脚本自己的函数跑当前数据：playbook 窗口 0.222、全样本 0.200、**只做多侧为 −0.174**。且原验证脚本算的是「周一收盘→周二收盘」，而本手册在**周一开盘**进场——**证据与执行的时钟不一致**。
>
> **因此本次修订**：仓位**减半**执行（§4）；撤回「已验证」措辞；以后引用任何历史数字必须同行标注 p=0.053 / Bonferroni=1.0 / 2 笔占 63%；新增机制监控指标（§8b）；**累计 8 次新的真实成交触发之前不考虑加仓**。
>
> 完整审计：`reports/red_team_weekend_gap.json`（七问逐条、含红队明确未发现的问题清单）

## 0. 一句话策略

> BTC 周末（周五收盘→周日收盘）涨跌幅 ≥5% 时，**周一开盘买入**加密概念股（MSTR/COIN/MARA），**周三收盘无条件卖出**。其余时间持有 SGOV，什么都不做。

原理假设：BTC 7×24 交易，美股一周只开 5 天，信息扩散存在时差。**红队确认这个前提在数据上成立（缺口确实不回补：2023-2025 回补率 0%），但成立的是「缺口」，而不是「我们拿得到的那一段」**——见上方审计结论。

## 1. 资金结构

```
总资产
├── 核心仓 80-90%：QQQ/QLD glide path 每月 DCA（见 docs/core_strategy.md，与本手册互不干扰）
└── 主动仓 10-20%：独立记账，只执行本手册
      ├── 默认状态：SGOV（短期国债 ETF，~4-5% 年化）
      └── 信号触发时按 §4 仓位表动用
```

**铁律：两仓资金永不混用。主动仓亏完不影响核心仓的 DCA 计划。**

## 4. 买入细则

- **标的**：MSTR / COIN / MARA 三只等权（信号 targets；COIN 上市前的历史触发日自动跳过）
- **时点**：周一开盘竞价，市价单。不挂限价等回落——缺口大概率不回补，等 = 踏空
- **仓位：v2.0 起减半执行**（红队降级判决）。下表数值**再乘以 0.5**：

| BTC 周末涨幅 | score | v1.0 仓位 | **v2.0 实际仓位（减半）** |
|---|---|---|---|
| 5.0% | 0.50 | 50% | **25%** |
| 7.5% | 0.75 | 75% | **37.5%** |
| ≥10% | 1.00 | 100% | **50%**（三只各 1/6） |

减半的理由：证据支持「符号为正、幅度高度不确定」（p=0.053、CI 含零、2 笔占 63% 毛利），而**不支持** v1.0 隐含的置信度。**累计 8 次新的真实成交触发（用真实成交价记录）之前不再加仓**——8 次可把标准误减半，若均值维持在 +5% 附近，p 会从 0.053 降到约 0.01。

单次事件最大亏损相应收窄（满仓 50% + 历史最差单笔约 -15% → 主动仓回撤上限约 -7.5%）。

## 4b. 报告口径（v2.0 强制修正）

**停用「每笔 +5.3%」这类误导性表述**，改用以下三个口径描述本策略：

| 口径 | 数值 | 说明 |
|---|---|---|
| 在场时间占比 | **2.73%**（5.69 年里 39/1429 个交易日） | 资金绝大部分时间在 SGOV，不在股市 |
| sleeve 税后年化 | **7.89%/年**（税前 10.98%，按 35% 短线税率） | 这是真正可与其它策略比较的数字 |
| 对总组合的贡献 | **约 1.5-3pp/年**（按 10-20% sleeve 摊算，税前） | v1.0 声称的「~14-15%/年」是 sleeve 口径，不是总组合口径 |
| 年触发次数 | 5(2021) → 2 → 2 → 3 → 1(2025) → 0(2026至今) | **硬约束：频率在枯竭** |

任何时候引用历史数字（+80.6% / 69% / +5.3%），必须**同行**标注：p=0.053、Bonferroni=1.0、2 笔占 63% 毛利。

## 5. 卖出细则（回测口径下的最优出场，**但注意**上方红队审计）

- **T+2 收盘无条件卖出**：周一买入 → 周三收盘卖出（收盘市价单 MOC，或收盘前 5 分钟市价单）。若周一是假期顺延至周二入场，则 T+2 顺延为周四收盘
- **不设止损**：-8% 硬止损经 64 个持仓腿的反事实对照——砍掉的回补型赢单（如 2021-01-04 MARA：止损 -8.2% vs 持有 +87%）大于救回的损单，且跳空会直接击穿止损价（2023-05-30 COIN 实际滑到 -21.7% 才成交）
- **不延长持有**：T+5 口径 MDD 从 -17% 恶化到 -26%，edge 只存在于 1-2 天
- **备选**：更看重低回撤者可用 T+1（周二收盘）——Sharpe 略高（0.85 vs 0.79）、MDD 更小（-12% vs -17%）、胜率更高（77% vs 69%），代价是总收益少约 17pp

## 6. 纪律清单（不该做的事）

1. **不做空**：历史 12 次 short 触发在任何出场规则下都是净亏损，不值得为它开 margin 账户
2. **不追二次入场**：信号只在周一有效。周一没上车，这一单就放弃
3. **不因「感觉还会涨」延长持有**：持有到 T+5 的口径已被回测否决
4. **不在 FLAT 时找别的理由交易**：空仓本身是策略的一部分（95% 时间的正确动作是不动）
5. **不动用核心仓资金**：任何情况下

## 8. 停用条件（什么时候不再信任这个信号）

平台是长期的，策略是轮换的——本信号也必须有下岗标准。以下任一触发 → 降半仓观察 + 重新回测归因：

1. 滚动最近 8 次触发的胜率 < 40%（历史基准 69%，但该基准本身不显著）
2. 累计回撤超过 **-25%**
3. 连续 3 次周一缺口被完全回补

## 8b. 机制监控（v2.0 新增——红队认定的**最该盯的指标**）

每次触发时**必须同时记录两个数**（这是判断「时差是否已被套利掉」的唯一探针）：

| 指标 | 定义 | 含义 |
|---|---|---|
| **gap** | 周五收盘价 → 周一开盘价 | 开盘一次性定价的幅度（**我们拿不到**） |
| **post-open** | 周一开盘价 → T+2 收盘价 | 我们实际能拿到的部分 |

历史对照（红队实测）：
- 2021-2023：gap 5.07% / post-open 5.85% / 回补率 22.2%
- 2024-2026：gap 8.18% / post-open 4.49% / 回补率 0%
- **2025 单看：gap +10.84% / post-open −0.09%**（行情全在开盘定价，策略一分没拿）

**退役判据**：若后续触发持续出现「gap 宽而 post-open ≈ 0」，即时差已被做市商/ETF 套利吃掉 → 退役本策略（保留平台与监控）。这是有明确机制解释的失效路径，比「胜率下降」更早、更可靠地报警。

## 9. 税务与成本

- 所有持仓 ≤3 个交易日 → **短线资本利得 = 普通所得税率**（联邦+州合计可能 30%+）。一年 2-3 次的高胜率大额单笔在税后会明显缩水，预期收益请按税后折算
- 交易成本：一年约 2-3 次触发 × 3 只 × 双向，IBKR 约 $300-600/年/每 10 万本金，可忽略

## 10. 已知局限（红队审计后更新）

1. **统计功效严重不足**：13 次做多，p=0.053、CI 含零、2 笔占 63% 毛利；真实前瞻均值可能在 0 到 +10.7% 之间，**只有新的样本外触发能解**
2. **搜索偏差**：本信号出自一次机遇式扫描（28 个假设方向），Bonferroni 校正后 p=1.0；且原始验证的「相关 0.823」不可复现、验证时钟与执行时钟不一致
3. **可能只是 beta 伪装**：所有对照（无条件每周末买入、持有到月末、随机日安慰剂）都不比它差或更好；本次交易的腿对 BTC 周末涨幅 R²=0.0007
4. **可交易段正在消失**：2025 年 gap +10.84% 而 post-open −0.09%；触发频率 5/年 → 0（2026 至今）
5. **滑点假设偏乐观**：5bps 假设存疑，开盘集合竞价是这些缺口股全天最宽的时刻（15-25bps 单边更现实；15bps 下累计从 90.2% 降到 83.3%）
6. **成本/税后真实回报小**：sleeve 税后年化 7.89%，对总组合贡献约 1.5-3pp/年
7. **其他信号未接入**：funding_rate（暂停）、onchain（防御性调节器，永不独立开仓）不在本手册执行范围
