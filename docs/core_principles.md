# 核心仓决策原则

不是规则手册。是五条原理，让你在任何手册没写到的情况下自己推导出正确动作。

## 原理一：你的财富 = 储蓄率 × 在场时间 × 杠杆效率

重要性从左到右递减。任何「该不该多投」的问题，先看它影响的是哪一项。

**多投影响储蓄率——最大的那个。** 所以有多余的钱（年终奖、副业收入、退税），答案是：投。按当前档位的比例直接买入，不等待回调，不分散到多个月。等待是择时，原理三告诉你为什么那不划算。

## 原理二：风险承受力 = 人力资本 ÷ 金融资本

人力资本是你未来还能赚到的钱（你现在最大的资产）。金融资本是账户里的数字。这个比值越高，你能承受的风险越大。

- 25 岁，账户 $30k，年入 $100k → 比值 33x → 风险承受力极高
- 45 岁，账户 $800k，年入 $150k → 比值 5x → 开始收敛
- 退休，账户 $2M，年入 $0 → 比值 0x → 风险承受力为零

**应用**：任何「我现在该不该更激进」的问题，算一下这个比值。比值高就激进（多买 QLD），比值低就保守（多买 QQQ）。滑翔表就是这张表的粗略版。

## 原理三：犯错的代价 ∝ 本金规模

$20k 账户亏 50% = 亏 $10k = 几个月工资。
$500k 账户亏 50% = 亏 $250k = 几年工资。

**同样的错误率，代价差 25 倍。** 所以：
- 本金小的时候：大胆，激进，多试。错了也只亏「几个月工资」
- 本金大的时候：保守，纪律，少动。错了亏的是「几年工资」

**应用**：账户 < $100k 时如果你犯了一个错（比如追高了、加仓太猛），不要自责——代价很小，学习价值很高。账户 > $500k 时，每做一个非标准动作之前想一遍：这个动作如果错了，我要用多少个月的储蓄来弥补？

## 原理四：崩盘对积累者是打折，对提款者是割肉

你现在的身份是积累者（每月往里放钱）。你未来某天的身份是提款者（每年往外取钱）。**同一个崩盘，对两种身份的意义完全相反。**

积累者遇到崩盘 = 你存入的钱购买力变强了 = 好事
提款者遇到崩盘 = 你卖出的资产折价了 = 永久损失

**应用**：
- 「市场跌了 30%，要不要停？」→ 你是积累者，跌 = 打折，继续买
- 「要不要抄底加仓？」→ 原理上对（积累者该欢迎折扣），但前提是你平时能保持纪律。如果你连正常月投都还没坚持一年，先证明自己能做到基础版
- 「什么时候开始怕崩盘？」→ 当你的年度提款额 > 年度储蓄额时。在那之前，崩盘是你的朋友

## 原理五：能执行的普通策略 > 执行不了的完美策略

每增加一条规则，就多一个你会在压力下打破它的机会。策略的价值不在回测数字里，在你能不能每个月那个早上真的打开 IBKR 下单。

**应用**：
- 发现自己在犹豫要不要按计划买入 → 这说明策略太复杂了，简化它
- 发现自己在市场暴跌时想要「优化」策略 → 这是情绪，不是理性。回到手册
- 发现自己三个月没看账户 → 这是好事，说明策略在正常工作

## 常见情景速查

| 情况 | 用哪条原理 | 正确动作 |
|---|---|---|
| 这个月有 $5000 额外收入 | 原理一 | 按当前档位比例一次性买入 |
| 加薪了 | 原理一 | 提高月投额（比优化策略有效 10 倍） |
| 市场跌了 30%，想加仓 | 原理四 | 原理上正确，但先问自己：平时月投你中断过吗？没有的话可以适度加 |
| 市场创新高，怕回调 | 原理五 | 不动。你的恐惧不是信号 |
| 失业了 | 原理二 | 人力资本骤降 → 暂停 QLD，只买 QQQ 或暂停 |
| 需要临时取钱 | 原理三 | 先卖 QQQ（低杠杆腿），保留 QLD（高杠杆腿） |
| 账户涨到下一档了 | 原理二+三 | 下月按新档位买入，年再平衡时调存量 |
| 账户跌回上一档了 | 原理二+四 | 自动回到更高杠杆档位，这是设计好的，不需要干预 |
| 想改策略 | 原理五 | 记下来，12 个月后如果还想改，再改。冷静期防冲动 |

---

*这五条原理的数据基础：1972-2026 纳斯达克综合指数 35 个入场队列实验、Kelly 准则（最优杠杆 ~2x）、Ayres-Nalebuff 生命周期投资理论、行为金融学（Bahrami-Tehrani et al. 2021：DCA 投资者在回撤期间停投的概率约 40%）。*
