# 核心仓策略：QQQ/QLD 滑翔定投

## 原理

一句话：年轻时用 1.5 倍杠杆放大敞口，随本金增长自动降杠杆。
依据：35 个入场队列实验中，该方案在 80% 的队列跑赢纯 QQQ、
0% 亏钱、最差成绩 1.68x（全场最佳）。不依赖任何信号或择时。

## 每月操作（5 分钟）

每月固定一天（几号都行，十年差距 0.7%），在 IBKR 上做两件事：

1. 查看当前 QQQ + QLD 的总市值
2. 查下面的表，确定当前的 QQQ/QLD 比例
3. 按该比例下单买入本月定投金额

## 滑翔对照表

| 账户总市值 | QQQ 买入比例 | QLD 买入比例 | 等效杠杆 |
|---|---|---|---|
| < $100k | 50% | 50% | 1.50x |
| $100k - $250k | 60% | 40% | 1.40x |
| $250k - $500k | 70% | 30% | 1.30x |
| $500k - $1M | 80% | 20% | 1.20x |
| > $1M | 100% | 0% | 1.00x |

用哪个档位：看下单那一刻的账户总市值（QQQ持仓 + QLD持仓 + 现金），
不是看累计投入。市值跌了就自动回到更高杠杆的档位——这正是滑翔
的机制：熊市里你自动加杠杆（因为本金缩了），牛市里自动降。

## 每年一次再平衡（1 月的定投日顺带做）

把存量持仓也调到当前档位的目标比例。
月度只调增量（新买的钱），年度调存量（已有仓位）。
差额不大就不动，超过 ±10 个百分点才调。

## 具体下单示例

假设月投 $2,000，当前账户 $85,000（第一档）：

```
IBKR 下单：
  买入 QQQ  $1,000  → 市价单
  买入 QLD  $1,000  → 市价单
```

三个月后账户涨到 $105,000（第二档），改为：

```
  买入 QQQ  $1,200
  买入 QLD    $800
```

## 佣金

IBKR Pro：$0.005/股，最低 $1/笔。每月两笔 = $2。
年化摩擦成本约 15bps，可忽略。

## 三条纪律

1. 暴跌不停投。2018Q4/2020/2022 的三次 -30% 都被这个策略的
   数据存活下来了，前提是坑底继续买入。
2. 不做任何择时。不因为「感觉要跌」而暂停，不因为「感觉要涨」
   而加码。你的优势是纪律，不是预测。
3. 需要用钱前 5 年，全部换 QQQ（跳到最后一档），不管市值多少。

## 什么情况下暂停或退出

| 情况 | 动作 |
|---|---|
| 失业 / 收入中断 | 暂停 QLD（杠杆腿），只买 QQQ 或暂停全部 |
| 5 年内要用钱 | 停买 QLD，存量逐步换 QQQ |
| 找到更好的策略 | 经 walk-forward 验证后再切换，不凭一次回测 |
| 市场崩盘 | 什么都不做。这就是策略设计要面对的 |

## 不做什么

- 不买 TQQQ（17% 概率二十年白干）
- 不做 EMA/信号切换（体制依赖，不稳定）
- 不做波动率目标（对定投是毒药）
- 不因为短期波动修改这张表

## 数据来源与局限

- 基于 1972-2026 纳斯达克综合指数（FRED）合成杠杆，35 个入场队列
- 只有 2 个独立 20 年样本，置信区间比表面看起来宽
- 不含股息（保守方向）
- 未建模税收（中国税务居民投美股的资本利得通常免税，股息扣 10%）
- 过去 50 年的纳斯达克不代表未来 20 年
