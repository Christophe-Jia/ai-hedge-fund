# 核心仓定投手册

## 你在做什么

每月固定一天，花 5 分钟，在 IBKR 买两只 ETF。年轻时带 1.5 倍杠杆，随本金增长自动降。不择时，不换仓，不因市场涨跌做任何调整。

## 每月操作

1. 打开 IBKR，查看 QQQ + QLD 的总市值（含现金）
2. 对照下表，确定当前比例
3. 按比例下单

| 账户总市值 | QQQ | QLD | 等效杠杆 |
|---|---|---|---|
| < $100k | 50% | 50% | 1.50x |
| $100k - $250k | 60% | 40% | 1.40x |
| $250k - $500k | 70% | 30% | 1.30x |
| $500k - $1M | 80% | 20% | 1.20x |
| > $1M | 100% | 0% | 1.00x |

几号买无所谓。市价单。每月两笔佣金共 $2。

## 示例

月投 $2,000，账户 $85,000 → 第一档：
```
买 QQQ $1,000
买 QLD $1,000
```
账户涨到 $120,000 → 第二档：
```
买 QQQ $1,200
买 QLD   $800
```

## 每年 1 月：再平衡

把存量持仓调到当前档位的目标比例。偏差 <10% 就不动。

## 三条规则

**崩盘不停投。** 你的钱在前期很小，跌 50% 也只亏几千美元。停投一个月的复利损失远大于任何单次回撤。

**不做任何判断。** 不因为「感觉要跌」暂停，不因为「感觉要涨」加码。

**要用钱前 5 年：全部换 QQQ。** 不管市值多少，跳到最后一档。

## 你会看到什么（提前打预防针）

| 场景 | 账户变化 | 持续时间 |
|---|---|---|
| 正常年份 | 月度 ±8% | — |
| 2022 式熊市 | -50%，账面腰斩 | 水下 2 年 |
| 2020 式闪崩 | -40%，三周内 | 3 个月回本 |
| 极端（2000-02） | -90%+ | 理论上可能，55 年一遇 |

如果你觉得自己扛不住 -50%：从 100% QQQ（无杠杆）开始，跑一年看自己的真实反应。能淡定面对 -15% 的月份，第二年再切 QLD。

## 什么时候暂停

- 失业 / 收入中断 → 暂停 QLD 腿，只买 QQQ
- 需要用钱 <5 年 → 停买 QLD，存量逐步换 QQQ

## 不要做的事

| 不做 | 原因 |
|---|---|
| 买 TQQQ | 17% 概率 20 年白干 |
| EMA/信号切换 | 牛市加速器，熊市出血点 |
| 波动率目标 | 对定投是毒药 |
| 崩盘时加码 | 好主意但行为要求太高，先做好基础版 |
